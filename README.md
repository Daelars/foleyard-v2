# Foleyard

Foleyard is a local-first sound library browser for large Collections of sound effects and music.

It indexes audio files from a folder on your machine and lets you browse, search, preview, favorite, and organize them into Collections (regular and smart), tags, and the Sound Shelf scratchpad.

Seven bundled tools (Sound Shelf, Make Pack, Drop Rules, Folder Janitor, Library Gatherer, Smart Collections, Auto Tag) extend the workspace in-process through the internal v2 extension API — no marketplace, no remote loading; all disabled by default. See [`docs/extensions-v2.md`](docs/extensions-v2.md) and [`docs/extensions-v2-migration.md`](docs/extensions-v2-migration.md).

Start here: [`docs/index.md`](docs/index.md) (all guides) and [`docs/quickstart.md`](docs/quickstart.md) (first run: add a root, scan, search, preview, organize).

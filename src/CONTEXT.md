# Application

The Application context is the user-facing Foleyard workspace. It coordinates browsing, searching, previewing, and organizing a local sound library.

## Language

**Foleyard**:
The local-first application through which a user works with their sound library.
_Avoid_: SoundSlop

**Library workspace**:
The user's active view of library content, navigation, selection, playback, and optional tools.
_Avoid_: Home page
